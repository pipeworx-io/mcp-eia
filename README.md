EIA MCP — US Energy Information Administration API v2

Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

| Tool | Description |
|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "eia": {
      "url": "https://gateway.pipeworx.io/eia/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use eia
```
